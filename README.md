# Astro Portfolio

A simple portfolio website built with [Astro](https://astro.build/).

## Project structure

- `package.json` — project metadata and scripts
- `astro.config.mjs` — Astro configuration
- `src/pages/index.astro` — homepage
- `src/layouts/BaseLayout.astro` — common layout wrapper
- `src/styles/global.css` — site styling

## Setup

```bash
cd c:\Users\91756\Desktop\portfolio\portfolio
npm install
```

## Run locally

```bash
npm run dev
```

Then open the local dev URL shown in the terminal.

## Build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Customize

- Edit `src/pages/index.astro` to update your name, about section, projects, and contact details
- Edit `src/styles/global.css` to adjust colors, spacing, and typography
